# NDD

Non-Dead Design, installed in this project: a method in which the project is specified by a conceptual map, kept in step with the code by the agent and the people working with it. The method is described by its own map, starting at [NDD](method/ndd.map.md#ndd); the project's map is `map.md` in the project root.

## Working with it

- Start any agent session as usual; the agent reads [`AGENT-RULES.md`](method/AGENT-RULES.md) and opens with a [Startup Scan](method/ndd.map.md#startup-scan) of the project's changes.
- Say `process`, `aside` or `pause` to keep a thought for later ([Keywords](method/ndd.map.md#keywords)).
- Read and sign off the map in the browser with `ndd/method/util/map_viewer.py` ([Map Viewer](method/ndd.map.md#map-viewer)); from another machine or a container, see [Map Viewer Access](method/ndd.map.md#map-viewer-access).

## This directory

The installer rewrites it on every run, so change nothing here: [`CHANGELOG.md`](CHANGELOG.md) names the installed version, and upgrading is a re-run ([Installation](method/ndd.map.md#installation)).
