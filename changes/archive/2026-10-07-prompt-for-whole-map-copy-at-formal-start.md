# Prompt for whole-map copy at Formal start

## Intent

When a Formal change's Change Specification will touch multiple map nodes, a whole-map copy as a companion asset is often cleaner than drafting proposed nodes inline in the change file — the user can diff edits in-editor against the committed baseline. The agent could assess this at the start of Formal planning and, when warranted, prompt the user to check in the baseline copy before editing begins. Opened as an aside 2026-10-07 after this exact pathway surfaced mid-walk in change 070. Overlaps with 070 (whose Change Specification narrowing already assumes map-only targets).
