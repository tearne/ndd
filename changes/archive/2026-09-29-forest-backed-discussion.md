# Forest-backed discussion

Parked pending scope review: on 2026-09-27, Discussion documents replaced the forest proposal. The approved Intent below is preserved as agreed at the time, not authorization to implement the superseded direction. See [current discussion](340-change-formality.md).

## Intent

Make the forest part of NDD’s normal process for developing and resuming discussions. Keep concise summaries of concepts, relationships, agreements, open questions and return points, preserving only history needed to understand current thinking. The user owns the concepts; the agent maintains the forest and guides review into changes with agreed Intents.

## Context

Discussion needs a resumable home before its purpose is settled enough for a change. The forest supports switching threads and connecting emerging ideas without creating a change document for every thought. Intent is the handover into work the user can review independently.

Harvested from [developing thoughts](forest.md#d4s--developing-thoughts), [turning thoughts into work](forest.md#h6v--turning-thoughts-into-work) and [forest administration](forest.md#f7n--forest-administration-and-method-integration). The current forest is a working example, not an approved storage specification. Approach definitions and Formal specification remain separate concepts for later harvesting.

Scope ends at the Intent handover and can use the existing change process. Redefining approaches and Formal remains separate. Intent is approved; further planning and implementation are deferred at the user’s request.
