# Field process feedback

**Change Style:** Formal

## Intent

Resolve three items of process feedback from field use. First, a bare *write* covers only content whose text was surfaced, not adjacent actions named in prose. Second, name where a Formal change's companion folder lives — `changes/open/`, beside its change file — and what happens to it at archive. Third, keep the Change Specification's whole-map copy note to a one-line pointer: that a copy is used, and its path.
