# Held release language

## Intent

Make the language for emptying Held read as resolving each item, not discarding it. "Release" is easy to take as letting go, so an agent can seem eager to throw material away. Clarify the wording in Held, Conclude and rule 17 so that folding an item into the change, or parking it, reads as the expected outcome, with discarding as the user's choice.

Raised as an aside (2026-10-17).
