# Node standard at draft and review

**Change Style:** Formal

## Intent

Check every node against the whole standard for a node, set by *Node Sections*, *Node Sizing* and *Writing Style*, at both moments it can slip: when the agent drafts it, before surfacing, and in Map Review, which adds only the map-wide checks a single draft cannot show. The standard includes keeping the mental picture in the body and the precision in *Detail*, so the body alone gives the reader the node and the precision stays findable.
