# Non-map specification targets

## Intent

Let a Formal Change Specification hold targets for non-map assets, derived or supplementary, in addition to the map nodes it proposes, kept inline or in the companion folder. Each is surfaced as a diff and approved like a node, and Build lands what was approved. Which assets are specified upfront is negotiated with the change. The map stays authoritative: a target overlapping its job is questioned.

## Context

Promoted from discussion [parking and session loss](../archive/2026-10-17-parking-and-session-loss-discussion.md) (2026-10-17). In change 020, non-map work had no approved home and landed unseen. Relaxes the map-only restriction from archived `2026-10-07-formal-specification-as-map-content`, whose concern was a parallel specification and not other assets.
