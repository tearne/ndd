# Writing style at draft

## Intent

Make the agent check every map draft against all of *Writing Style* before surfacing it. The agent rules carry only *Formatting*, and no flow read routes the agent to *Conceptual Writing* or *Economy* before drafting, so drafts arrive with fragments, interrupted sentences, provenance and repetition, and the user has to ask for each review. Settle whether a broader agent rule or a flow read closes the gap.

## Context

Set aside during 095's planning (2026-11-03), after the user had to ask for a *Writing Style* review on successive drafts. It also absorbs 075 Duplication drift: an edit restating a fact where it is added, rather than linking to the fact's owner, is an *Economy* failure the check should catch, as 070's sweep found.
