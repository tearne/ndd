# Agent as stack manager

## Intent

Strengthen Orient Then Focus and Held with the idea of the agent as a **stack manager**: the user is free to throw out a thought at any point — a side question, a digression, an idea for later — and the agent holds it appropriately, whether that means looking at it now, taking a short digression, or parking it, and then returns the user to where they were. The user directs their full attention to the item in hand without keeping breadcrumbs, trusting that nothing is lost. The motivating experience: mid-review of a node, the user wants to press enter on a stray thought immediately rather than let it mix into their review notes and produce a text bomb that prompts an overwhelming reply.

Open when picked up: whether this is a principle, a strengthening of Orient Then Focus, or a rule about Held; what the agent says when it parks versus takes up an item; and how a digression is closed and the user returned.
