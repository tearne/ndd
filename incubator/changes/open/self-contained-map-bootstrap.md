# Self-contained map with in-file bootstrap

## Intent

Today the method ships as a `map.md` alongside a separate `BOOTSTRAP.md` that tells a fresh agent how to orient. The appeal: collapse that to a single self-contained file — e.g. `ndd.map.md` — where a variant of the bootstrapping text lives at the very top, so the entire NDD method travels as one map file that explains how to read and act on itself. Explore whether the bootstrap can fold into the map's own META region (or a preamble above the root) without muddying the map, and what a consumer project then installs.

May want reconciling with `70-distribution-and-upgrade.md`, which covers how the method is distributed and upgraded into consumer projects.
