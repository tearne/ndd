# Quick jump to the map tree overview

**Kind:** idea
**Anchor:** m6x

The tree overview sits at the end of the root node, but there's no fast way to jump straight to it — you land at the top of the file and scroll. Jumping by node name doesn't work because the root node's name isn't a fixed convention. Consider a stable, conventional anchor for the tree overview (e.g. a fixed heading or marker) so an editor can jump to it directly regardless of the root's name.
