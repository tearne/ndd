# Do node ids earn their place?

## Intent

Change 220 settled that nodes are cited outside the map by name alone, not *name (id)*: a stale name still carries searchable words, a stale id matches nothing, and only a pure rename ever favoured the id. That leaves the `id` with no consumer — links resolve by name, citations now do too — so the scaffolding block, the id rules in Node Identity and the review step that adds missing ids carry no weight today.

Before removing them, weigh the stakeholder review process for nodes (enhancement discussion, P2): per-node sign-off would need node-level metadata, and the yaml scaffolding block is where it would live. The question is whether the block and its id are kept for that, repurposed, or dropped.
