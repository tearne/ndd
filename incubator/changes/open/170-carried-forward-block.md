# Carried-forward block in a change document

## Intent

Formalise the **carried-forward block** — material captured early in a change document that is destined for a later part rather than the one it currently sits in. Capturing a thought when it arrives is valuable, but parking it inside a capped part (an [Intent](#intent), say) is unfair to that part's character cap, since nobody intends to keep it there.

Scope when picked up: name it, say where it lives in the document, state that it is exempt from the soft-trigger caps, and say when it must be empty — plausibly absorbed by the part it was aimed at, in the way an [aside](#aside-keyword) must be settled before [Conclude](#conclude). Relates to Intent, Approach, Aside Keyword, and Enjoyment (artifact economy).

Parked via aside during change 160's planning (2026-08-28), prompted by exactly this pattern arising when 160's over-long parked Intent was trimmed.
