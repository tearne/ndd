# Navigation should signal parent vs sibling

**Kind:** idea
**Anchor:** b3q

The current nav-link block lists parent and child links as a flat list, so the higher-vs-sibling (and parent-vs-child) relationships between linked nodes aren't obvious at a glance. Consider a convention that makes the direction of each link visible without a reader having to cross-reference — while keeping links name-anchored and markdown-navigable.
