# Thought Management

**Cadence:** Wander

## Intent

_(Approved 2026-09-11, reframed from "Agent as stack manager". Build started the same day.)_

Bring the ways a stray thought is handled into one account, Thought Management, so the user can throw out a question, a digression or an idea at any point and keep no breadcrumbs. A thought is answered now if a line will do, taken as a short digression, held for the current change, or parked as its own; each placement is acknowledged in a line. While a set is in progress every message ends with a status line showing the stack, such as *map edits 3 of 7 > aside*, with *· held 2* when Held is not empty.

## Context

Parked during change 150's build (2026-09-10) as "Agent as stack manager": the user wants to press enter on a stray thought immediately rather than let it mix into review notes and produce a text bomb, trusting the agent to hold it and return them to where they were. On 2026-09-11 the user reframed it as Thought Management: Held, Aside and the agent's stack brought into one order that builds confidence, with a compact status line rather than anything elaborate. The `>` separator was chosen because it reads as nesting; `/` was rejected as a fraction. Home: a new child of Orient Then Focus, which is already over the size bound.
